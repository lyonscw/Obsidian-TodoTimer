# TodoTimer 需求说明

整理日期：2026-10-20

## 1. 目标

在 Obsidian 中直接使用 Markdown 记录零碎、连续、存在前后依赖的日常工作。围绕同一个任务持续补充后续行动、进展、卡点和等待事项，快速看出每件事做到哪里、为什么暂时无法推进。

记录过程不要求精心分类、设置标签或为每次情况变化新建独立笔记，也不要求把每条进展都变成新的待办任务。

本文是 TodoTimer 首版的功能与验收依据；实现及验证结果另见验证记录。

## 2. 记录结构

| 类型 | Markdown 表达 | 用途 |
| --- | --- | --- |
| 任务 | `- [ ] 任务内容` | 需要完成的事项 |
| 子任务 | 在上级任务下缩进的复选框任务 | 为推进上级事项而产生的后续行动，可继续嵌套 |
| 普通记录 | 在任务下缩进的普通列表条目 | 说明进展、卡点、等待对象或其他情况 |

- 支持手动输入复选框任务，也支持通过 Obsidian 的操作创建复选框。
- 父子任务独立勾选，不自动改变彼此的完成状态。
- 普通记录不强制使用“进展：”“卡点：”“等待：”等前缀，这些只是便于阅读的写法。
- 普通记录的自动时间仅作用于任务下的非空列表条目，不影响其他正文和普通列表。
- 任务、普通记录及时间均直接保存在 Markdown 原文中，关闭插件后仍能阅读。

## 3. 已确认的时间规则

### 3.1 任务创建

新建非空任务并结束本次输入后，在行末自动追加一次创建时间：

```md
- [ ] 上架 XXXX 系统到测试 📝 20260101 17:00
```

- 格式固定为 `📝 YYYYMMDD HH:mm`。
- 0.1.3 起使用该创建图标，完成标记保持 `✅`；已有的 `💪`、`[🆕]` 创建时间和 `[✅]` 完成时间仍兼容识别，不批量迁移笔记。
- 后续修改任务内容、调整缩进或移动任务，不刷新已有创建时间。
- 已有创建时间时不重复追加。

### 3.2 任务完成

手动勾选复选框时，在行末追加完成时间，同时保留创建时间：

```md
- [x] 上架 XXXX 系统到测试 📝 20260101 17:00 ✅ 20260103 14:20
```

- 格式固定为 `✅ YYYYMMDD HH:mm`。
- 同一任务只保留一个当前完成时间，不因继续编辑或重新打开笔记重复追加。

### 3.3 取消完成

手动取消勾选时，删除该任务行末的 `✅` 及其对应时间（如果存在）。保留创建时间、任务内容和下方记录。

```md
- [ ] 上架 XXXX 系统到测试 📝 20260101 17:00
```

再次勾选时记录新的完成时间，不累计多次完成或重开的历史标记。

### 3.4 普通记录

任务下新增的普通记录只在行末追加时间，不添加 `📝`、`✅` 或其他图标：

```md
  - 等待：网络管理员开通权限 20260102 10:40
```

- 格式固定为 `YYYYMMDD HH:mm`。
- 每条非空普通记录只追加一次，后续修改内容不刷新已有时间。
- 情况发生变化时，可以在同一任务下新增一条普通记录，保留前后过程。

## 4. 完整示例

```md
- [ ] 上架 XXXX 系统到测试 📝 20260101 17:00
  - 卡点：需要先明确访问范围，才能申请网络权限 20260102 08:00
  - [x] 统计访问系统并整理网络规则 📝 20260102 08:05 ✅ 20260102 10:30
  - 等待：网络管理员开通权限，申请已提交 20260102 10:40
```

上级任务保持未完成；网络规则子任务已完成；普通记录解释当前阻塞原因与等待事项。后续继续在原任务下补充即可。

## 5. 已确定的交互与范围

以下约定已纳入首版开发计划：

- **平台与范围**：Windows 桌面优先，所有 Markdown 笔记生效；实时预览、源码模式和阅读视图均支持任务状态与完成时间的维护。
- **粘贴与拖入**：保留原样，不补创建时间；已有时间不变。粘贴后仅修改文字也不补创建时间。
- **任务转换**：明确将普通文字转换为复选框任务，按新建任务处理。
- **旧任务完成**：勾选无创建时间的旧任务时，仅增加本次完成时间，不倒填创建时间。
- **提前完成**：新任务尚未离行就勾选时，一次写入创建和完成时间。

- **输入结束**：按 Enter、光标实际离开该行、切换笔记或进入阅读视图时，为新建的非空条目补时间。
- **继续输入**：停顿、同一行内移动光标、确认中文候选、短暂失焦和后台自动保存都不算结束输入，不插入创建时间。
- **空条目**：空复选框和空普通列表条目不加时间。
- **时间来源**：使用设备本地时间，24 小时制，精确到分钟；条目内容与时间之间保留一个空格。
- **旧笔记**：打开笔记不批量补时间；仅修改旧条目文字不应被当作新建条目。不将当前时间伪装成旧内容的创建时间。
- **编辑连续性**：自动补时间保持光标位置，不打断输入，支持正常撤销。
- **历史与输入法**：撤销、重做不重取当前时间；中文输入法确认候选期间不插入时间。时间采用实际补写时刻。
- **阅读视图写入**：源任务必须准确定位并核对最新内容。有同文件且内容一致的编辑器时使用一次编辑事务；纯阅读时一次原子写入，撤销能力以宿主为准，不额外提供独立撤销系统。定位不确定则不写入，并提示操作未执行。
- **快捷操作**：沿用 Markdown 的输入、换行、缩进和复选框交互，无需额外表单或分类步骤。

## 6. 外观要求

- 任务正文与层级清晰，适合快速浏览和持续追加记录。
- 时间统一位于行末，在实时预览或阅读视图中适度弱化，保持可读。
- 可将时间显示为紧凑标签，但不改变原文规定的时间格式；普通记录仍只呈现时间，不增加图标。
- 优先沿用 Obsidian 的任务、缩进和折叠体验，不引入独立任务看板或复杂管理面板。

## 7. 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 手动输入新的非空复选框任务 | 输入结束后追加一次创建时间 |
| 通过 Obsidian 的操作创建非空复选框任务 | 按同样规则追加创建时间 |
| 修改已有任务文字、缩进或位置 | 原创建时间保持不变，不重复追加 |
| 勾选任务 | 追加一次完成时间，保留创建时间 |
| 取消勾选已完成任务 | 仅删除该任务的完成标记及时间 |
| 取消勾选后再次完成 | 写入本次完成时间，不保留前一次完成时间 |
| 勾选或取消勾选子任务 | 不自动改变父任务、其他子任务的状态 |
| 在任务下新增普通记录 | 行末仅追加 `YYYYMMDD HH:mm`，没有图标 |
| 修改已有普通记录 | 不刷新、不重复追加已有时间 |
| 创建空条目 | 不添加时间 |
| 编辑任务之外的普通正文和列表 | 不自动添加时间 |
| 打开含有旧任务的笔记 | 不批量补时间或重复追加已有时间 |
| 自动插入时间后继续输入、撤销 | 光标和编辑过程正常，修改可以撤销 |
| 关闭插件查看 Markdown 原文 | 任务层级、记录内容及时间仍完整可读 |

以上为实现与验证的标准，实际通过情况记录在验证文档中。
